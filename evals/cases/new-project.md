# Forward-test case: new project

Use `$dev-flow` to design and scaffold a new Rust background worker with a React administration console. Resolve any personal/team/project profiles separately from the neutral public core. The request is intentionally broad. The worker needs scheduled jobs, local state, structured logs, and a small table/chart UI.

The evaluator should observe how the flow scans the empty/new repository state, builds an instruction ledger, treats the new administration UI as material, selects co-design, confirms users/product/UX before production UI, applies dependency preferences, asks before new dependencies, and avoids unnecessary multi-agent ceremony.
