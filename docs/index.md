# Dev Flow documentation

This index routes contributors and agents to the smallest maintained knowledge owner for the task. Source code, tests, manifests, CI, and release artifacts remain authoritative for executable facts.

## Product and operating model

- [Project governance](project/dev-flow-governance.md): product boundaries, task model, continuity, capability ownership, and safety posture.
- [Repository knowledge](knowledge-system.md): durable knowledge ownership, progressive disclosure, and document placement.
- [Methodology pool](methodology-pool.md): bounded assurance-method selection and limitations.
- [Confidentiality-aware AI work](confidentiality-aware-ai-work-v1.md): sensitive-data handling and disclosure boundaries.

## Evaluation and release

- [Flow Activation Coverage](evaluation-suite.md): deterministic and model-semantic activation evidence.
- [Release model](releasing.md): R1-R4 qualification, exact candidate evidence, installation, and action-specific authority.
- [Canonical product state](../governance/product-state.json): current source, published/stable, rollback, and delivery/qualification status.
- [Project catalog](project/catalog.json): machine-readable project documentation inventory.
- [Changelog](../CHANGELOG.md): released and unreleased product changes.
